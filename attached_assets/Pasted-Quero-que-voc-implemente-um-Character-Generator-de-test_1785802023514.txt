Regra de agrupamento dos arquivos

Os arquivos seguem este padrão:

Exemplo base
backhair1.png
Exemplo de variações desse mesmo item
backhair1_c1.png

Interpretação correta

Se existir:

backhair1.png
backhair1_c1.png
backhair1_c2.png

Então isso significa que existe uma família/base chamada:

backhair1

E ela possui as variantes:

padrão/default = backhair1.png
variante c1 = backhair1_c1.png
variante c2 = backhair1_c2.png
Regra de parsing

Para cada categoria:

Identifique os arquivos .png.
Agrupe por “base name”.
Um arquivo sem sufixo _cN é a variante padrão/default.
Arquivos com sufixo _cN são variantes daquela mesma base.
Exemplo
crown1.png
crown1_c2.png
crown1_c3.png
crown1_c4.png
crown1_c5.png

Interpretação:

família/base = crown1
variantes disponíveis:
default
c2
c3
c4
c5
Observação importante

Pode existir item sem variação.
Nesse caso ele deve aparecer normalmente com apenas uma opção.
