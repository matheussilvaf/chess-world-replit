Crie um aplicativo web completo para monitorar seguidores de perfis públicos do Instagram.



Não quero apenas uma interface demonstrativa. Quero que o sistema realmente execute o monitoramento.

Funcionamento principal

Na tela inicial, quero poder criar vários monitoramentos.



Para criar um monitoramento, o usuário deve apenas informar:



URL do perfil público do Instagram;

frequência de monitoramento.



Exemplo:



https://instagram.com/usuario



Não precisa existir nenhuma opção perguntando se o perfil é público ou privado. O aplicativo será usado somente com perfis públicos.

Ao criar um monitoramento

O sistema deve identificar o perfil do Instagram e começar a monitorá-lo.



Dentro de cada monitoramento, quero visualizar:



foto do perfil;

nome;

username;

número atual de seguidores;

lista dos seguidores;

quantidade de seguidores novos;

quantidade de seguidores que saíram;

data e horário da última verificação;

histórico das alterações.

Monitoramento dos seguidores

O objetivo principal do aplicativo é identificar exatamente quem começou a seguir e quem deixou de seguir o perfil monitorado.



Na primeira verificação, o sistema deve obter a lista atual de seguidores e utilizá-la como referência inicial.



Nas verificações seguintes, deve comparar a nova lista de seguidores com a lista anterior.



Exemplo:



Lista anterior:



@joao

@maria

@pedro

@carlos



Nova lista:



@joao

@maria

@pedro

@fernanda



O sistema deve identificar:



Novo seguidor
+ @fernanda começou a seguir



Deixou de seguir
- @carlos deixou de seguir



É exatamente esse comportamento que eu quero.



Não quero apenas saber que o número passou, por exemplo, de 10.000 para 10.001 seguidores.



Quero saber qual usuário entrou e qual usuário saiu.

Lista de seguidores

Dentro de cada monitoramento deve existir uma área mostrando todos os seguidores atualmente identificados.



Para cada seguidor, mostrar quando possível:



foto;

username;

nome;

link para o Instagram.



Também deve existir pesquisa para encontrar rapidamente um usuário na lista.

Histórico de alterações

Quero uma seção semelhante a uma timeline.



Exemplo:



18:45
+ @fernanda começou a seguir



18:32
- @carlos deixou de seguir



17:51
+ @lucas começou a seguir



Cada alteração deve permanecer registrada para consulta posterior.



Se uma pessoa seguir, deixar de seguir e depois seguir novamente, o histórico deve preservar todas essas alterações.

Atualização automática

O sistema deve verificar os perfis automaticamente.



Quero poder definir frequências como:



5 minutos;

10 minutos;

30 minutos;

1 hora;

6 horas;

12 horas;

1 dia;

3 dias;

5 dias;

10 dias.



Se for melhor, também permita uma frequência personalizada.



As novas informações devem aparecer automaticamente no painel sem eu precisar atualizar manualmente a página.

Tela principal

Quero uma tela mostrando todos os monitoramentos criados.



Exemplo:



@usuario1



12.580 seguidores



+ 14 novos



- 7 saíram



Última verificação: 18:40



Status: Monitorando

@usuario2



4.210 seguidores



+ 2 novos



- 1 saiu



Última verificação: 18:38



Status: Monitorando



Ao clicar em um monitoramento, abrir a página completa daquele perfil.

Página do monitoramento

Quero algo aproximadamente assim:



@usuario



12.580 seguidores



+14 novos hoje



-7 saíram hoje



Depois:

Alterações

Lista de pessoas que começaram ou deixaram de seguir.

Seguidores

Lista completa dos seguidores identificados.

Histórico

Histórico das verificações e alterações.

Gráfico

Mostrar a evolução do número de seguidores ao longo do tempo.



Permitir visualizar períodos como:



24 horas;

7 dias;

30 dias;

90 dias;

tudo.

Status do monitoramento

O monitoramento pode apresentar estados como:



Monitorando;

Verificando agora;

Pausado;

Erro;

Perfil indisponível.



Quero poder:



pausar monitoramento;

retomar monitoramento;

executar uma verificação manual;

alterar a frequência;

excluir monitoramento.

Coleta das informações

Utilize a melhor forma disponível para obter as informações públicas necessárias do Instagram.



Se for necessário utilizar web scraping ou automação de navegador para conseguir identificar os seguidores públicos, implemente isso.



O sistema precisa tentar obter a lista necessária para conseguir comparar as verificações e identificar quem entrou e quem saiu.



Se você sugerir ou utilizar Playwright, Puppeteer, alguma API, serviço de scraping ou qualquer outra ferramenta:



se você julgar que existe uma outra ferramenta melhor, use a outra melhor.



Essa regra vale para todo o projeto.



Não quero determinar:



banco de dados;

framework;

backend;

frontend;

ORM;

sistema de jobs;

sistema realtime;

bibliotecas específicas.



Você deve analisar o projeto e escolher sozinho as tecnologias que considerar mais adequadas.

Importante

Não invente informações.



Se uma verificação falhar ou não conseguir obter a lista inteira de seguidores, não considere automaticamente que as pessoas desapareceram da lista.



Por exemplo:



Se existiam 10.000 seguidores e uma verificação conseguiu carregar somente 3.000, o sistema NÃO deve informar que 7.000 pessoas deixaram de seguir.



Nesse caso, simplesmente considere aquela verificação incompleta e tente novamente posteriormente.



Essa proteção é muito importante.

Interface

Quero uma interface:



moderna;

profissional;

limpa;

simples;

responsiva;

fácil de entender.



Não quero aparência de protótipo.



Priorize principalmente desktop, mas faça funcionar corretamente também no celular.

Objetivo final

O aplicativo deve me permitir abrir qualquer monitoramento e responder imediatamente:



Quantos seguidores esse perfil possui agora?

Quem são os seguidores?

Quem começou a seguir recentemente?

Quem deixou de seguir recentemente?

Quando essa alteração aconteceu?

Quantos seguidores entraram hoje?

Quantos saíram hoje?

Como o número de seguidores mudou ao longo do tempo?



O foco absoluto do projeto é:



monitorar continuamente a lista de seguidores de perfis públicos do Instagram e detectar exatamente quais usuários começaram ou deixaram de seguir.



Implemente o sistema completo e escolha por conta própria as melhores tecnologias para realizar isso.



Sempre que existir uma solução técnica melhor do que alguma ferramenta inicialmente considerada, utilize a solução melhor.



Nao sei como voce vai fazer pra usar ferramentas inteligentes para fazer o web scrape da pagina,  visto que a meta nao tem api pra isso, mas utilize web scrpaes inteligentes pra fazer isso. e deixe tudo em tempo real
