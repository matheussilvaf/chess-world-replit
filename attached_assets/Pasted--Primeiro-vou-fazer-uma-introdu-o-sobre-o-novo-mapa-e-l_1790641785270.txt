


Primeiro vou fazer uma introdução sobre o novo mapa e logo abaixo eu vou explicar o que eu quero. Adicionei um novo mapa chamado tactics-academy.tmj dentro de world-v2. Este vai ser a área interna da tactics academy quando o jogador clicar para adentrar. Este mapa esta composto por 3 salas: Sala dos bots, onde tem 4 tabuleiros, que sao 4 bots e ao lado direito uma área onde futuramente vou pedir pra você adicionar estatisticas, mas por enquanto nao faça nada nessa parte. A sala do meio é a sala dos puzzles, onde temos um tabuleiro central, com os puzzle diário, e os outros 4 tabuleiros ao reador sao tabuleiros onde o jogador pode criar desafios de puzzle. A ultima sala de cima é a lesson room, uma sala de lições. onde o jogador vai poder aprender e praticar. Todos os tabuleiros dessa mapa seguem a mesma estrutura dos outros tabuleiros do mapa, então voce vai apenas replicar toda a funcionalidade jogavel de xadrez. Como voce pode ver na segunda imagem, eu criei uma pasta para cada tabuleiro, e dentro de cada pasta tem exatamente as object layers que voce vê na terceira imagem. Você já sabe como implementar o xadrez no tabuleiro, pois isso já existe no jogo, entao nao preciso explicar mais nada.  Tem a object layer building_interactions onde tem um objeto retangular chamado tactics_academy_exit_interactios, onde o jogador vai poder sair de lá e retornar ao mapa anterior. A object layer spawns tem o pin tactics_academy_entry_spawn, que é o spawn do jogador ao entrar. A object layer collisions tem todas as colisões do mapa, faça funcionar.
